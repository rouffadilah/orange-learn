# orange-learn Workflow Canvas V10

Pembaruan area kerja Workflow Builder:

- Zoom 50%–200% dari tombol toolbar dan mouse wheel.
- Zoom mengikuti posisi pointer agar navigasi terasa natural.
- Pan dengan drag area kosong, middle mouse, atau tahan Space + drag.
- Fit otomatis ke seluruh node.
- Reset tampilan 100%.
- Grid dapat dinyalakan/dimatikan.
- Ukuran grid dapat dipilih: kecil, normal, besar, sangat besar.
- Snap ke grid dapat dinyalakan/dimatikan.
- Toolbox dan Inspector dapat disembunyikan untuk memperluas area kerja.
- Preferensi canvas disimpan di browser.
- Posisi/zoom/pan/grid/snap ikut disimpan saat workflow diekspor sebagai JSON.
- Shortcut: Wheel=Zoom, drag kosong=Pan, Space+drag=Pan, 0=Fit, 1=100%, G=Grid, S=Snap, Delete=hapus node, Esc=batalkan koneksi.
