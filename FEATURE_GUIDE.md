# orange-learn — Panduan Fitur Visual

Versi ini menambahkan halaman `/fitur` dan `/fitur/<slug>` untuk pembelajaran Orange Data Mining.

Fokus visual:
- Struktur canvas + widget + channel dibuat ulang secara orisinal untuk pembelajaran.
- Setiap fitur memiliki ikon, kategori, level, input-output, fungsi, kapan digunakan, langkah penggunaan, dan mini workflow.
- Halaman anatomy menjelaskan port input, konfigurasi, dan port output pada widget.
- Panduan mencakup 30 widget/fitur inti lintas Data, Transform, Visualize, Model, Evaluate, Unsupervised, dan Text Mining.
- AI Tutor memanfaatkan data panduan fitur ini sebagai konteks tambahan ketika pertanyaan relevan.

Sumber konsep dan daftar kategori/fitur: Widget Catalog dan materi resmi Orange Data Mining. Visual pada orange-learn bukan salinan screenshot resmi.
